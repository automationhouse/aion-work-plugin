# Folder współdzielony zewnętrznym narzędziem

Czytaj w kroku 6 drzewa przygotowania w `references/setup.md`, gdy zespół korzysta z dysku sieciowego lub folderu synchronizowanego przez inną usługę.

1. Ustal ścieżkę lub link w pytaniu z drzewa i sprawdź tylko wskazane miejsce. Ścieżka dostępna na komputerze użytkownika może być niedostępna w chmurze. Korzystaj z obsługiwanego przez hosta udostępniania folderu; wymagane zgody systemu lub dostawcy wykonuje użytkownik.
2. Ustal dostawcę, administratora dostępu, stan połączenia i zgłaszany stan synchronizacji. Brak informacji oznacza stan nieznany. Odczyt lub zapis lokalny nie dowodzi widoczności u współpracownika. Gdy potrzeba, wskaż weryfikację przez istniejący proces zespołu; nie wysyłaj wiadomości bez upoważnienia.
3. Odczytaj istniejące instrukcje zespołu przed proponowaniem struktury. Zachowaj pliki. Nie dodawaj prywatnych profili, tokenów ani stanu konfiguracji konkretnego komputera. Uzgodnione, jawne dopasowania pracownika należą do `AION_USERS/` według `working-folder.md` w MCP AION WORK i kroku 11c setupu. Jeśli sprawdzenie zapisu jest potrzebne, użyj uzgodnionego pliku tymczasowego; nie nadpisuj dokumentu w ramach próby.
4. Wróć do pytania 6a o wspólną edycję, jeśli zasad nie da się odczytać. Przed zmianą pliku przeczytaj go ponownie i sprawdź, czy nie zmienił się od poprzedniego odczytu. To zmniejsza ryzyko, ale nie jest blokadą. Stosuj blokady i historię wersji dostawcy, jeśli istnieją. Przy konkurencyjnych zmianach zachowaj obie wersje i uzgodnij rozwiązanie; nie nadpisuj pracy kolegi po cichu.
5. Jeśli dostawca nie zapewnia bezpiecznej koordynacji, uzgodnij osobne pliki wynikowe lub przekazywanie edycji. Git nie jest wymagany. Przy istniejącym repozytorium ustal jego zasady; nie inicjalizuj nowego, nie dodawaj automatycznie adresu zdalnego i nie współdziel zapisywalnego `.git` między pracownikami.
6. Zgłoś potwierdzony zakres odczytu i zapisu, sposób współdzielenia oraz niepewności synchronizacji. Uprawnienia dostawcy są niezależne od członkostwa w AION. Wróć do drzewa.
