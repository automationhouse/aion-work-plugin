# Folder współdzielony zewnętrznym narzędziem

Czytaj przy podłączaniu folderu według `references/setup.md`, gdy zespół korzysta z dysku sieciowego lub folderu synchronizowanego przez inną usługę.

1. Wykorzystaj znaną ścieżkę lub link; poproś o nie tylko przy braku miejsca i sprawdź tylko wskazane miejsce. Ścieżka dostępna na komputerze użytkownika może być niedostępna w chmurze. Korzystaj z obsługiwanego przez hosta udostępniania folderu; wymagane zgody systemu lub dostawcy wykonuje użytkownik.
2. Ustal dostawcę, administratora dostępu, stan połączenia i zgłaszany stan synchronizacji. Brak informacji oznacza stan nieznany. Odczyt lub zapis lokalny nie dowodzi widoczności u współpracownika. Gdy potrzeba, wskaż weryfikację przez istniejący proces zespołu; nie wysyłaj wiadomości bez upoważnienia.
3. Odczytaj istniejące instrukcje zespołu przed proponowaniem struktury. Zachowaj pliki. Nie dodawaj prywatnych profili, tokenów ani stanu konfiguracji konkretnego komputera. Uzgodnione, jawne dopasowania pracownika należą do `AION_USERS/` według `working-folder.md` w MCP AION WORK. Jeśli sprawdzenie zapisu jest potrzebne, użyj uzgodnionego pliku tymczasowego; nie nadpisuj dokumentu w ramach próby.
4. Gdy zasad wspólnej edycji nie da się odczytać, zacznij od osobnego pliku wynikowego. Uzgodnij koordynację przed zmianą wspólnych danych. Przed zmianą pliku przeczytaj go ponownie i sprawdź, czy nie zmienił się od poprzedniego odczytu. To zmniejsza ryzyko, ale nie jest blokadą. Stosuj blokady i historię wersji dostawcy, jeśli istnieją. Przy konkurencyjnych zmianach zachowaj obie wersje i uzgodnij rozwiązanie; nie nadpisuj pracy kolegi po cichu.
5. Jeśli dostawca nie zapewnia bezpiecznej koordynacji, przygotuj osobne pliki wynikowe w zleconym zakresie albo uzgodnij przekazywanie edycji przed zmianą wspólnego pliku. Git nie jest wymagany. Przy istniejącym repozytorium ustal jego zasady; nie inicjalizuj nowego, nie dodawaj automatycznie adresu zdalnego i nie współdziel zapisywalnego `.git` między pracownikami.
6. Zgłoś potwierdzony zakres odczytu i zapisu, sposób współdzielenia oraz niepewności synchronizacji. Uprawnienia dostawcy są niezależne od członkostwa w AION. Kontynuuj pierwsze zadanie.
